# Skills

A collection of custom Claude Code skills.

## Available skills

### [`staging-audit`](./staging-audit/)
Post-handoff design QA — compares a Figma annotated flow against a staging build and outputs an XLSX inconsistency report with embedded screenshots, severity rankings, and columns for dev comments and designer sign-off.

**Invoke:** `/staging-audit`

---

To add a new skill, create a subfolder with a `SKILL.md` inside it.
